## Введение

Этот документ описывает **сценарий выполнения** (*deployment script*) для развёртывания веб-приложения на сервере. Инструкция подходит как для ~~новичков~~ **начинающих**, так и для ***опытных инженеров***.

## Требования

### Ненумерованный список (предварительные условия)

- Установленный **Docker** версии 20.10+
- Доступ к репозиторию по **SSH-ключу**
- Настроенный домен и SSL-сертификат
- Минимум 2 ГБ оперативной памяти
  - 4 ГБ рекомендуется
  - 8 ГБ для production-среды

### Нумерованный список (шаги сценария)

1. Клонировать репозиторий:
   ```bash
   git clone git@github.com:example/app.git
   ```
2. Перейти в директорию проекта и создать `.env`-файл
3. Собрать Docker-образ
4. Запустить контейнеры через `docker compose up -d`
5. Проверить статус сервисов
6. Настроить reverse-proxy (Nginx)

---

## Сценарий выполнения

### Этап 1. Подготовка окружения

Убедитесь, что все зависимости установлены. Если чего-то не хватает — установите через пакетный менеджер.

### Этап 2. Сборка и запуск

```bash
# Сборка образа
docker build -t myapp:latest .

# Запуск
docker compose up -d
```

### Этап 3. Проверка работоспособности

Выполните команду `curl http://localhost:8080/health` — сервис должен вернуть `OK`.
